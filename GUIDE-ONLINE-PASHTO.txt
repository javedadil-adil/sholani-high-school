------------------------------------------------------------
  ۱. supabase.com خلاص کړئ، وړیا اکاونټ جوړ کړئ.

     جوړ یې کړئ او Public یې کړئ.

  ۶. Settings > API کې Project URL او anon key کاپي کړئ او
     په config.js کې یې ولیکئ (د YOUR-PROJECT او
     PASTE-YOUR-ANON-KEY-HERE پر ځای).

     GitHub کې نوی repo جوړ کړئ (نوم: sholani-school-online)،

     https://YOUR-USERNAME.github.io/sholani-school-online/
     (YOUR-USERNAME د خپل GitHub نوم سره بدل کړئ — په index.html،
     sitemap.xml او robots.txt کې هم همغه ځای‌نیونکی بدل کړئ.)

  په دې وسیله کې ښکاري. کله چې Supabase وصل شي، اپلوډ ټولو ته ښکاري.
